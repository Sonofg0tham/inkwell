Straight answer

Inkwell is now suitable for supervised personal use and a clearly labelled public beta. The normal editing path is real, including a single-line input, textarea, contenteditable editor and an embedded srcdoc editor.

The exact ZIP was extracted and installed into fresh Chromium. Trusted typing produced a suggestion and badge, keyboard Apply changed teh to the in each top-level editor, and the embedded editor completed its check without console, page or runtime errors.

It is not equivalent to the full Grammarly product. The beta does not include Google Docs, multilingual checking, Firefox or Safari, collaborative documents, plagiarism detection, or generative rewrite tools.

What changed

Proofreading reliability

Five English dictionaries and high-confidence grammar rules now run locally. They still return useful corrections when the contextual model fails.

Long documents are chunked safely, short fields such as teh are checked, stale requests are cancelled and model results are anchored to exact source text.

Privacy and security

First-run consent is mandatory. Remote custom endpoints follow the same per-site rule as built-in cloud providers.

HTTP is limited to localhost and 127.0.0.1. Other endpoints need HTTPS and an exact runtime grant. Website content scripts never receive provider credentials.

Web editing

Field discovery now covers dynamic editors, nested open shadow roots and same-origin blank frames while using metadata to skip recognised sensitive and code fields.

The badge aggregates frame state, errors remain visible, and closed-shadow controls prevent page CSS or scripts from reading suggestion text.

Usability and access

Suggestion cards support keyboard focus, Escape, Tab loops, Apply, Dismiss, Ignore all and Add to dictionary. The re-entrant keyboard Apply crash found by the installed test is fixed.

Settings now expose five dialects and personal dictionary management. Desktop and 390px mobile views were captured and reviewed.

Provider safety

Saved endpoints are validated again in the background. Connection tests require a structured proofreading completion instead of accepting a reachable but unsuitable model.

Gemini requests omit a deprecated sampling field, model output is schema-limited, page prompt injection is treated as untrusted data and results are never auto-applied.

Release engineering

CI now audits the full dependency tree, typechecks, runs capped-worker tests, builds Chrome and Edge, installs pinned Chromium and smoke-tests the extension.

WXT and Playwright are pinned, the old vulnerable runner chain is gone, and the release checklist includes exact-ZIP and store-policy gates.

Issues and limits still open

MediumPublic security and privacy links are not live yet

PRIVACY.md and SECURITY.md are included in the release branch, but their final main branch URLs will not resolve until the pull request is merged. Private vulnerability reporting is disabled on the GitHub repository.

Fix: merge the reviewed release pull request, then enable Settings > Security > Code security and analysis > Private vulnerability reporting. Verify both public links in a signed-out browser before submitting the store listing.

MediumThe declared Chrome 102 floor was not directly exercised

The packaged extension passed on current Playwright Chromium and Microsoft Edge 150. Chrome 102 is the declared compatibility floor, but this pass did not run that older browser version.

Fix: before calling the release stable, smoke-test Chrome 102 and Edge 102, or raise minimum_chrome_version to a version covered by the compatibility test matrix.

MediumSensitive-field detection remains heuristic

Inkwell uses field types, autocomplete values, labels and common editor markers. A custom field can hide its purpose from every browser extension.

Fix: this limit is disclosed in the product and policy. Users should disable Inkwell on sensitive sites and prefer a local provider where possible. Future releases can extend the metadata patterns as real cases are reported.

LowModel issue categories are not always precise

Qwen corrected the planted errors, but sometimes labelled grammar corrections as spelling. The correction still anchors and applies safely, though category filters may be imperfect.

Fix: keep deterministic rules authoritative, retain the structured model qualification and review category accuracy when evaluating future default models.

Product scopeNo full Grammarly parity claim

The public copy now calls Inkwell a Chromium beta and lists the unsupported surfaces. Closing the remaining commercial-suite gap would be a product roadmap, not a release hardening patch.
